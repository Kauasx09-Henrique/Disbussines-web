## 💡 O Propósito

O **DisBusiness** nasceu de uma necessidade real: **microempreendedores** muitas vezes possuem excelentes produtos ou serviços, mas carecem de ferramentas acessíveis para organizar seu negócio e ganhar visibilidade digital.

Este projeto é uma **plataforma web** desenvolvida para preencher essa lacuna, oferecendo uma interface amigável onde o pequeno empreendedor pode gerenciar suas informações e apresentar seu trabalho de forma profissional, sem a complexidade de sistemas empresariais pesados.

---

## ✨ Funcionalidades Principais

O sistema foi dividido em módulos focados na dor do usuário final:

### 🏢 Para o Empreendedor (Painel de Gestão)
- **Gestão de Catálogo:** CRUD completo para adicionar, editar e remover produtos/serviços.
- **Perfil Profissional:** Edição de informações de contato, horários e descrição do negócio.
- **Controle de Visibilidade:** Ferramentas para destacar o que há de melhor no negócio.

### 🌐 Interface Pública (Vitrine)
- **Design Atrativo:** Layout focado em converter visitantes em clientes.
- **Busca e Navegação:** Facilidade para encontrar produtos ou serviços específicos.
- **Responsividade:** Acesso perfeito via Celular, Tablet ou Desktop.

---

## 🎨 UI/UX e Design System

Um dos grandes diferenciais do DisBusiness é o foco na **Experiência do Usuário**.
Não basta funcionar, tem que ser agradável.
- **Navegação Intuitiva:** Menus claros e fluxos de ação simplificados.
- **Identidade Visual:** Uso de cores e tipografia modernas para transmitir confiança.
- **Feedback Visual:** Validações de formulário e mensagens de sucesso/erro claras.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído sobre uma base sólida e amplamente suportada na web:

| Camada | Tecnologia | Detalhes |
| :--- | :--- | :--- |
| **Backend** | **PHP** | Lógica de negócios robusta, processamento de formulários e sessões. |
| **Banco de Dados** | **MySQL** | Modelagem relacional para garantir a integridade dos dados dos clientes. |
| **Frontend** | **HTML5 & CSS3** | Estruturação semântica e estilização responsiva. |
| **Interatividade** | **JavaScript** | Manipulação do DOM e dinamismo na interface. |
